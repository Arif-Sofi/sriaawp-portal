## Conventions (enforced; the reviewer checks them)

- const only, no reassignment; early returns, max 1 level of if-nesting; max 3 positional params (object beyond; React props exempt); no emojis; minimal comments.
- Tailwind v4 config-less: semantic token utilities only (`bg-card`, `text-muted-foreground`, ...); no raw hex; NO `dark:` variants — theming flips via the `.dark` class (`@custom-variant dark`).
- React 19 compiler on: no forwardRef / useMemo / useCallback. `"use client"` only where hooks or handlers are used.
- Next.js 16: route gating in `proxy.ts` (not `middleware.ts`); mutations via Server Actions returning `ActionResult<T>`; `cookies()` is async.
- Every mutating server action must `revalidatePath(...)` the routes that render the affected data, on the SUCCESS path only (after the DB write + audit, before `return ok`); client mutation components do not refresh server components on their own. Established repo-wide in PR-B (#72).

## Pitfalls — do not repeat

- Prettier: a route-group glob like `src/app/(public)/**` breaks (parens are extglob) and aborts the run; format new files by explicit path. A broad `src/lib/**` reformats unrelated base-branch files — target only this PR's new files.
- Seed/scripts load `dotenv/config`, which reads `.env`, not `.env.local`; pass `DOTENV_CONFIG_PATH=.env.local` (or `dotenv_config_path=.env.local` with `node -r dotenv/config`).
- `Cannot find module` for a dependency listed in package.json -> run `npm install` (lockfile had it, node_modules did not).
- Supabase: use the direct or session connection for the seed (transaction pooler :6543 rejects prepared statements). There is no `db:migrate` script; apply SQL with the `.simple()` runner.
- Subagents may touch files outside scope and may introduce a module-level `let`; review the diff and revert stray changes (for example accidental formatting of base-branch files). Use `crypto.randomUUID()` for ids, not a counter.
- Tailwind v4 `container` is now centered with `padding-inline: 1rem` via an `@utility container` override in `globals.css` (PR #56, `fix/center-layout`, the base of the gap-backlog train). It no longer sits flush-left, but it still has only 1rem of horizontal padding — do not assume large gutters. Any branch that needs this centering must stack on `fix/center-layout` or later.
- A persistent nav row in an authenticated layout must be wrapped in `container` (use `PortalNav`/`RoleNav`); `AppShortcuts` alone has no `container`, so placed in a layout's nav slot it renders flush to the viewport edge.
- A component on a colored bar (`bg-primary`) must use the matching `*-foreground` token, never the base color token (`text-primary` on `bg-primary` is invisible). Prefer opacity for inactive states (`text-primary-foreground/70`).
- `Button` is not polymorphic; for a link styled as a button use `<Link className={buttonClasses({variant,size})}>`, do not hand-duplicate classes.
- Migrations (settled approach): do NOT run `npm run db:generate` — its journal numbering collides with the hand-authored RLS files. Instead update the Drizzle schema files (for ORM types) AND hand-author the migration SQL with the next sequential number (applied so far: 0000, 0001, 0002, 0003, 0004; NEXT is 0005), matching the DDL style of `0002_content_audit.sql`. Leave `supabase/migrations/meta/*` and `_journal.json` untouched so `npm run db:check` stays green. Apply only the NEW file via `node -r dotenv/config scripts/_apply.mjs supabase/migrations/000N_*.sql dotenv_config_path=.env.local`, then re-seed and verify with `scripts/_counts.mjs`. Never re-run 0000/0001 (no IF NOT EXISTS).
- Handle expected DB constraint violations in server actions (unique = SQLSTATE `23505`) and return `fail(msg, {fieldErrors})`; never let them surface as a 500.
- Build Postgres array predicates with drizzle `arrayOverlaps(col, values)`, not string-interpolated array literals.
- Display dates/times in `Asia/Kuala_Lumpur` explicitly (the deploy server tz is UTC): pass `timeZone` to `toLocaleString`/`toLocaleDateString`, and derive any calendar `dateISO` in the same tz.
- A seed insert for a table with no natural unique key needs a presence guard (skip if a row already exists); `onConflictDoNothing()` without a real unique target still inserts duplicates on every re-seed.
- Do NOT claim adopting Supabase Auth 'lights up RLS for free' - in v1 the app connects via the service-role key (rls-policy-design.md notes 2-3) which BYPASSES the RLS in 0001_rls_policies.sql; those policies are correct-but-bypassed and only enforce on the v2 authenticated-key path. App layer is the live gate; RLS is defense-in-depth (ADR-019).
- Branch off the STACK TIP, not main: `docs/phase-1/` and the feature code are not on main yet, so a branch cut from main loses the whole tree. Base new branches on the current stack tip and set the PR base to it (a main-based PR shows the entire stack diff).
- Bash `>` redirect to `/tmp` and Windows Python disagree on the path (MSYS /tmp vs C:	mp). Pipe `gh ... | python -` or write to an absolute Windows path; do not redirect to /tmp then read it from python.
- The Windows console is cp932 and cannot print em-dash/Japanese; a print crash mid-loop can leave a batch half-applied. Call `sys.stdout.reconfigure(encoding='utf-8', errors='replace')` before printing issue/ADR text.
